# singcue PRD (기능 명세서)

Oct 21, 2026 · @Louis Choi

## 목적과 범위

singcue는 음성 명령으로 노래 연습 구간을 제어하는 웹 앱이고, 이 문서는 기획서의 로드맵 5단계를 기능별 사용자 스토리와 인수 조건으로 나눕니다.

- **포함**: YouTube 임베드 재생 제어, 구간 마킹, 음성 정지·시작 명령, 구간 끝 동작, 가사·시간 매핑, 구절 인식 점프, 연습 기록과 리포트
- **제외**: 음원·영상 다운로드, 가사 제공, 로그인과 기기 간 동기화, 서버(백엔드), 스피커 환경 보증, 자모 단위 유사도 계산(최적화 단계에서 검토)
- **기준 문서**: singcue 프로젝트 기획서와 2026-10-21 PoC 결과입니다. 인수 조건의 수치는 PoC 로그에서 가져왔습니다.
- **읽는 법**: ID는 F(단계)-(번호)이고, 인수 조건은 합격과 불합격을 직접 확인할 수 있게 적었습니다.

## 사용자와 핵심 시나리오

사용자는 노래의 어려운 구간을 반복해서 연습하는 사람 한 명이며, 사용 환경은 PC의 Chrome, 이어폰, 마이크 권한 허용입니다. 스피커에서는 동작을 보증하지 않습니다.

1. 연습할 곡의 YouTube 링크를 붙여 넣어 영상을 불러옵니다.
2. 재생하면서 연습할 구간의 시작과 끝을 마킹하거나, 구절과 시작 시간을 입력해 둡니다.
3. "시작"이라고 말하면 마킹한 위치보다 프리롤만큼 앞에서 재생이 시작되고, 구간 끝에 도달하면 설정에 따라 멈추거나 반복합니다.
4. 노래를 따라 부르다가 "멈춰"나 "스톱"이라고 말하면 재생이 멈춥니다.
5. 멈춘 뒤 직전 구절을 말하면 그 다음 구절부터 재생됩니다.
6. 연습이 끝나면 구간별 연습 횟수와 시간을 리포트에서 확인합니다.

## 기능 요구사항

요구사항은 로드맵 단계 순서로 정리했고, 각 단계 끝의 완료 기준은 로드맵의 게이트와 같습니다.

### 1단계. 영상 불러오기와 구간 마킹

| ID | 사용자 스토리 | 인수 조건 |
| --- | --- | --- |
| F1-1 | 연습자로서 YouTube 링크를 붙여 넣어 영상을 불러오고 싶다 | 영상 주소(watch, youtu.be, shorts, embed 형식)나 영상 ID를 입력하면 공식 임베드 플레이어에 영상이 준비된다. 잘못된 입력은 오류로 안내하고, 임베드가 막힌 영상은 플레이어 오류 코드를 안내하며 앱은 멈추지 않는다 |
| F1-2 | 연습자로서 지금 위치를 시작점으로 표시하고 싶다 | "여기부터" 버튼을 누르면 현재 재생 위치가 시작 위치로 저장되고 분:초로 표시된다 |
| F1-3 | 연습자로서 구간의 시작과 끝을 직접 찍고 싶다 | 시작과 끝을 각각 마킹하면 구간 하나로 저장되고, 구간을 여러 개 저장할 수 있다. 끝이 시작보다 앞서면 저장하지 않고 안내한다 |
| F1-4 | 연습자로서 저장한 구간을 골라 연습하고 싶다 | 구간 목록에서 하나를 선택하면 연습 구간이 된다. 시작 명령, 구간 끝 동작, 연습 기록이 이 구간을 기준으로 동작한다 |
| F1-5 | 연습자로서 버튼으로도 재생과 정지를 하고 싶다 | 재생 버튼은 선택한 구간의 시작 위치(프리롤 적용)부터 재생하고, 정지 버튼은 재생을 멈춘다 |

**완료 기준**: 마킹한 구간이 버튼 조작으로 시작 위치부터 재생된다.

### 2단계. 음성 명령과 재생 제어

| ID | 사용자 스토리 | 인수 조건 |
| --- | --- | --- |
| F2-1 | 연습자로서 음성 인식을 버튼으로 켜고 끄고 싶다 | 버튼으로 켜고 끌 수 있고, 켜면 사용 중인 마이크 장치 이름과 입력 레벨이 보인다. 마이크 권한이 거부되면 안내하고, 인식 세션이 끝나면 자동으로 다시 시작한다 |
| F2-2 | 연습자로서 "멈춰"라고 말해 재생을 멈추고 싶다 | 재생 중 정지 명령어(기본: 잠깐, 스탑, 스톱, 정지, 멈춰, stop)가 인식되면 정지 상태가 된다. 인식 결과를 받은 뒤 0.1초 이내에 정지하고, 이어폰 환경에서 재생 중 10번 말해 9번 이상, 노래하는 중 10번 말해 7번 이상 정지한다 |
| F2-3 | 연습자로서 "시작"이라고 말해 연습 구간을 재생하고 싶다 | 재생 중이 아닐 때 시작 명령어(기본: 시작, 재생해, 틀어줘, 음악큐)가 인식되면 구간 시작 위치에서 프리롤만큼 앞에서 재생한다. 인식 결과를 받은 뒤 0.5초 이내에 재생 상태가 되고, 3초 안에 재생되지 않으면 자동재생 차단 가능성을 안내한다 |
| F2-4 | 연습자로서 노래를 부르다가 가사 때문에 명령이 잘못 실행되지 않길 원한다 | 명령어를 뺀 나머지 글자가 2자(초기값, 설정 가능)를 넘으면 명령으로 처리하지 않고 "무시"로 표시한다. 명령어가 섞인 가사 문장은 재생 중이든 아니든 실행되지 않는다 |
| F2-5 | 연습자로서 상태에 맞는 명령만 받아 주길 원한다 | 재생 중에는 정지 명령만, 재생 중이 아닐 때는 시작 명령과 구절 점프만 실행한다. 직전 명령 후 0.8초 안의 명령은 무시한다 |
| F2-6 | 연습자로서 정지가 더 빨리 반응하길 원한다 | 정지 즉시 실행 옵션을 켜면 정지 명령을 중간 인식 결과로 실행하고, 끄면 최종 결과로 실행한다. 두 방식의 반응 시간을 측정해 기본값을 정한다 |
| F2-7 | 연습자로서 구간 앞부분을 놓치지 않고 들어가고 싶다 | 프리롤(기본 1.5초) 설정만큼 앞에서 재생을 시작하고, 시작 위치가 프리롤보다 앞이면 0초부터 재생한다 |
| F2-8 | 연습자로서 구간 끝에서의 동작을 고르고 싶다 | 구간 끝 도달 후 1초 이내에 설정대로 동작한다. 자동 정지(기본)는 정지 상태가 되고, 자동 반복은 구간 시작으로 돌아가 정지 명령 전까지 반복 재생하며, 계속 재생은 구간과 상관없이 이어서 재생한다 |
| F2-9 | 연습자로서 명령어를 내 말투에 맞게 바꾸고 싶다 | 정지·시작 명령어 목록을 수정할 수 있고, 수정한 목록은 다시 접속해도 유지된다. 기본 목록은 줄이지 않고 제공한다 |

**완료 기준**: 정지와 시작이 말로 동작해 이어폰 환경에서 시연할 수 있다.

### 3단계. 가사·시간 매핑

| ID | 사용자 스토리 | 인수 조건 |
| --- | --- | --- |
| F3-1 | 연습자로서 구절과 시작 시간을 직접 입력하고 싶다 | "분:초 구절" 형식으로 한 줄에 하나씩 입력하면 구절 목록이 되고, 인식된 구절 수가 표시된다. 형식에 맞지 않는 줄은 구절로 세지 않는다 |
| F3-2 | 연습자로서 재생하며 구절의 시작 시간을 찍고 싶다 | 목록에서 구절을 고르고 재생 중 버튼을 누르면 현재 위치가 그 구절의 시작 시간으로 기록되고 목록에 바로 반영된다 |
| F3-3 | 연습자로서 마지막 구절을 말해도 이동할 곳이 있길 원한다 | 목록 끝에 시간만 적은 줄을 넣으면 "마지막 구절 다음 위치"로 쓰고, 이 줄은 구절 수에 세지 않는다 |
| F3-4 | 연습자로서 입력한 매핑을 저장하고 다시 불러오고 싶다 | 매핑을 JSON 파일로 내보내고 불러오면 같은 구절과 시간이 복원된다. 매핑은 사용자 기기에만 저장하며 서버로 보내지 않는다 |
| F3-5 | 개발자로서 가사와 음원을 배포물에 넣지 않고 싶다 | 저장소와 배포물에 가사·음원이 포함되지 않고, 예시 데이터는 직접 만든 가상의 구절만 쓴다 |

**완료 기준**: 구절과 시간을 입력해 저장하고, 내보낸 파일을 불러오면 같은 내용이 복원된다.

### 4단계. 구절 인식 점프

PoC에서 정확히 인식된 구절은 유사도 0.85\~1.00이었고, 오인식이 잦은 구절은 0.50\~0.89였습니다. 기준 0.5에서는 PoC의 어려운 구절 9번이 모두 통과했습니다.

| ID | 사용자 스토리 | 인수 조건 |
| --- | --- | --- |
| F4-1 | 연습자로서 직전 구절을 말해 다음 구절부터 연습하고 싶다 | 재생 중이 아닐 때 구절을 말하면 인식 후보(최대 5개)를 모두 입력한 구절과 비교해 가장 비슷한 구절을 찾는다. 유사도가 기준(기본 0.5) 이상이면 그 다음 구절의 시작 시간에서 프리롤만큼 앞에서 재생한다. 말하듯 읽었을 때 10번 중 8번 이상 올바른 다음 구절로 이동한다(초기 합격선) |
| F4-2 | 연습자로서 잘못 인식됐을 때 그 사실을 알고 싶다 | 유사도가 기준 미만이면 이동하지 않고, 가장 가까운 구절과 유사도 점수를 보여 주며 다시 말하도록 안내한다 |
| F4-3 | 연습자로서 마지막 구절을 말했을 때의 동작을 알고 싶다 | 마지막 구절이 인식되면 "마지막 구절 다음 위치"가 있을 때 그 위치에서 프리롤만큼 앞에서 재생하고, 없으면 이동하지 않고 이유를 안내한다 |
| F4-4 | 연습자로서 유사도 기준을 곡에 맞게 조절하고 싶다 | 기준을 0\~1 사이에서 바꿀 수 있고 기본값은 0.5이다. 바꾼 값은 다음 인식부터 적용된다 |
| F4-5 | 연습자로서 노래하는 중에는 구절 점프가 일어나지 않길 원한다 | 재생 중에는 구절 인식 결과로 이동하지 않는다(F2-5와 같은 규칙) |

**완료 기준**: 정지 상태에서 구절을 말하면 그 다음 구절 위치에서 재생된다.

### 5단계. 연습 기록과 리포트

| ID | 사용자 스토리 | 인수 조건 |
| --- | --- | --- |
| F5-1 | 연습자로서 충분히 연습한 경우만 횟수로 세고 싶다 | 구간 재생이 최소 재생 시간(기본 3초) 이상 이어지면 연습 1회로 기록하고, 그보다 짧게 멈추면 기록하지 않는다. 최소 재생 시간은 설정에서 바꿀 수 있다 |
| F5-2 | 연습자로서 연습 기록이 남기를 원한다 | 1회마다 구간, 날짜와 시각, 재생 시간을 브라우저 저장소에 저장하고 새로고침해도 유지된다 |
| F5-3 | 연습자로서 어느 구간을 몇 번 연습했는지 보고 싶다 | 리포트에 구간별 연습 횟수, 총 연습 시간, 날짜별 추이를 보여 주고, 숫자가 저장된 기록을 직접 센 값과 일치한다 |
| F5-4 | 연습자로서 기록을 백업하고 옮기고 싶다 | 기록을 JSON으로 내보내고 불러올 수 있다. 사이트 데이터를 지우면 기록이 사라진다는 안내를 화면에 표시한다 |

**완료 기준**: 연습 기록이 쌓이고 리포트의 숫자가 기록과 일치한다.

## 설정 항목

사용자가 바꿀 수 있는 값은 8개이고, 기본값은 기획서와 PoC에서 정했습니다.

| 항목 | 기본값 | 선택지·범위 | 단계 |
| --- | --- | --- | --- |

| 정지 명령어 | 잠깐, 스탑, 스톱, 정지, 멈춰, stop | 목록 편집 | 2 |

| 유사도 기준 | 0.5 | 0\~1 | 4 |
| 연습 1회 최소 재생 시간 | 3초 | 변경 가능 | 5 |

## 비기능 요구사항

| 항목 | 요구사항 |
| --- | --- |
| 반응 시간 | 인식 결과를 받은 뒤 정지는 0.1초 이내, 재생은 0.5초 이내에 상태가 바뀐다(PoC: 정지 3\~6ms, 재생 264\~389ms). 최종 인식 결과는 첫 중간 결과보다 0.85\~1.3초 늦게 나온다 |
| 환경 | PC의 Chrome(PoC는 Chrome 155), 이어폰 사용, HTTPS 또는 localhost(마이크 사용 조건). 다른 브라우저와 스피커는 보증하지 않는다 |
| 안정성 | 음성 인식 세션이 끝나면 자동으로 다시 시작하고 오류는 화면에 안내한다. PoC에서 세션 재시작과 오류는 0회였고, 장시간 안정성은 개발 후 점검한다 |
| 프라이버시 | 음원, 가사, 연습 기록을 서버로 보내지 않는다. 다만 브라우저의 음성 인식(Web Speech API)은 음성이 브라우저 제공사 서버로 전송될 수 있어 화면에 안내 문구를 표시한다 |
| 저작권 | YouTube 공식 임베드 플레이어만 사용하고, 영상·오디오 추출 도구와 비공식 자막 추출은 쓰지 않는다. 시연 영상은 공유저작물, CC 라이선스 곡, 직접 녹음한 곡으로 만든다 |
| 저장 | 구간, 매핑, 기록, 설정은 브라우저 저장소에 저장하고 JSON으로 내보내고 불러올 수 있다 |

## 미확정 사항과 개발 후 점검

### 미확정 사항
