# 2026-10-21 구간 마킹·저장·선택 (#6)

## 1. 배경 / 문제

- PRD F1-2~F1-4: "여기부터" 버튼으로 현재 재생 위치를 시작으로 표시해 분:초로 보여 주고, 시작과 끝을 마킹하면 구간 하나로 저장하며(여러 개 가능), 끝이 시작보다 앞서면 저장하지 않고 안내한다. 저장한 구간 목록에서 하나를 고르면 연습 구간이 되고, 새로고침해도 영상별 구간이 유지되어야 한다.
- 기술 설계 문서는 이 기능을 컨트롤러(구간 reducer), storage, 화면에 나눠 두었다. storage 어댑터(#2)와 영상 불러오기 화면(#5)은 main에 있다.
- 영상 불러오기 화면의 `PlayerView`는 플레이어를 안에서만 쓰고 바깥에 내주지 않아, 현재 재생 위치를 읽을 방법이 없었다.

## 2. 검토한 선택지

- **구간 저장 방식**
  - "여기부터"·"여기까지"를 누르고 별도의 "저장" 버튼으로 확정: 끝을 고칠 기회가 있지만 버튼이 하나 늘고, 인수 조건("시작과 끝을 각각 마킹하면 구간 하나로 저장")보다 단계가 많다.
  - 끝을 마킹하는 순간 저장: 버튼 두 개로 끝난다. 끝이 잘못되면 시작 표시를 남겨 두어 끝만 다시 찍으면 된다.
- **저장 시점**: 구간 목록이 바뀔 때 효과(useEffect)로 저장하기와, 동작을 처리하는 이벤트 처리기 안에서 바로 저장하기. 효과로 하면 처음 불러온 목록을 다시 쓰지 않도록 구분하는 표시가 필요하다.
- **현재 위치 전달**: `PlayerView`에 플레이어를 넘겨받는 콜백을 두기와 ref를 두기. 콜백은 매 렌더마다 새 함수가 되면 효과가 다시 실행돼 플레이어를 다시 만들 수 있다.

## 3. 결정 및 이유

- 끝을 마킹하는 순간 저장한다. 길이가 0인 구간도 연습할 수 없으므로 끝이 시작과 같아도 "끝이 시작보다 앞서는" 경우와 같이 저장하지 않고 안내한다. 시작 없이 끝을 누르면 시작을 먼저 표시하라고 안내한다.
- reducer(`src/controller/sectionReducer.ts`)는 순수 함수로 두고, 새 구간의 id는 동작에 담아 넘긴다(reducer 안에서 난수를 쓰지 않아 테스트가 결정적이다).
- 저장은 이벤트 처리기에서 reducer로 다음 상태를 계산해 구간 목록이 바뀐 경우에만 한다. 영상이 바뀌면 `key={videoId}`로 패널을 새로 만들어 초기화 함수에서 그 영상의 구간을 읽는다. 효과를 쓰지 않아 처음 불러온 목록을 다시 쓰는 일이 없다.
- 저장 직전에 같은 영상 데이터를 다시 읽어 `sections`만 바꾼다. 가사 매핑(`lines`, `endT`, #16)을 다른 화면이 같은 키에 쓰더라도 지우지 않기 위해서다. storage 어댑터는 수정하지 않았다.
- 위치는 0.1초 단위로 맞춰 저장하고, 화면에는 분:초(초 아래 버림)로 보여 준다.
- 연습 구간 선택은 저장하지 않고 화면 상태로만 둔다. `VideoData`에 선택을 담을 항목이 없고, 이슈 범위에서 새로고침 후 유지가 필요한 것은 구간 목록이다.
- `PlayerView`에는 선택 항목 `playerRef`를 추가했다. ref는 렌더마다 같아 효과가 다시 실행되지 않는다. 플레이어가 준비되면 담고, 요청이 바뀌거나 화면에서 빠지면 null로 돌린다.

## 4. 구현 내용

- `src/controller/sectionReducer.ts`: 상태 `{ sections, start, selectedId, notice }`, 동작 `markStart`, `markEnd`(id 포함), `select`. 안내는 `'no-start' | 'end-before-start'`. 이름은 `구간 N`. `selectedSection()` 도우미.
- `src/controller/useSections.ts`: `useSections(videoId, storage)` 훅과 `saveSections()`(같은 영상 데이터를 다시 읽어 구간만 바꿔 저장). 저장 실패(`SaveResult`)를 돌려준다.
- `src/ui/formatTime.ts`: 초 → 분:초.
- `src/ui/SectionPanel.tsx`: "여기부터"·"여기까지" 버튼, 표시한 시작 위치, 안내, 구간 목록(`aria-pressed` 버튼), 현재 연습 구간 표시. 저장 실패 시 새로고침하면 사라진다고 안내한다.
- `src/ui/PlayerView.tsx`: `playerRef` 선택 항목.
- `src/ui/App.tsx`: `playerRef`를 만들어 `PlayerView`에 넘기고, 영상이 준비되면 `SectionPanel`을 `key={videoId}`로 연결. `app.css`에 패널 스타일.

## 6. 남은 작업 / 보류 사항

- 연습 구간 선택은 새로고침하면 풀린다. 유지가 필요하면 저장 위치(설정 또는 영상 데이터)를 정해야 한다.
- 구간 이름 바꾸기, 삭제, 시작·끝 수정은 이번 범위가 아니다. 삭제가 생기면 `구간 N` 이름이 겹칠 수 있어 이름 규칙을 다시 정한다.
- 플레이어가 아직 준비되지 않아 현재 위치를 읽지 못하면 마킹 버튼은 아무것도 하지 않는다. 패널은 영상이 준비된 뒤에만 보이므로 실제로는 드물다.
- 재생 버튼(F1-5), 시작 명령·구간 끝 동작·연습 기록이 선택한 구간을 쓰도록 연결하는 일은 컨트롤러(`usePlayback`) 이슈에서 다룬다. 그때 `PlayerView`의 `playerRef`를 컨트롤러로 옮길 수 있다.
