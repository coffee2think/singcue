# 2026-10-22 MVP 개발 일시 중단

## 1. 배경 / 문제

- PRD 단계 1~5의 기능 이슈(#1~#14, #16~#24, #26~#29)와 버그 #53이 모두 main에 병합됐다.
- 열린 이슈는 측정 게이트 #15(이어폰 환경 음성 명령 검증)와 #25(구절 점프 정확도 검증) 두 개다. 둘 다 코드 작업이 아니라 사람이 이어폰을 끼고 직접 말해서 재는 작업이다.
- 사용자가 다른 프로젝트에 집중해야 해서, 게이트를 측정하지 않은 채 개발을 멈추기로 했다.
- 나중에 돌아왔을 때 "어디까지 확인됐고 무엇이 남았는지"를 바로 복원할 수 있도록 중단 시점의 상태를 남긴다.

## 2. 검토한 선택지

- **게이트까지 마친 뒤 중단**: PRD 단계 2·4의 완료 기준을 확정할 수 있지만, 사용자가 직접 측정할 시간이 필요하다.
- **게이트 이슈를 닫고 중단**: 이슈 목록은 깔끔해지지만 미검증 사실이 묻힌다.
- **게이트 이슈를 열어 둔 채 중단하고 상태를 기록**: 측정은 미루되 남은 일을 잃지 않는다.

## 3. 결정 및 이유

- 게이트 이슈 #15, #25는 열어 둔 채 개발을 중단한다.
- 현재 상태는 **"기능 구현 완료, PRD 목표 수치 미측정"**이다. PRD 단계 2와 4의 완료 기준이 이 측정에 걸려 있으므로 MVP 완료로 보지 않는다.
- 같은 PR에서 ESLint 검사 제외 목록에 `.claude`를 추가했다. 병렬 세션이 `.claude/worktrees/`에 남긴 작업 사본까지 검사돼, 로컬 `npm run lint`가 저장소 코드와 무관한 오류 639건을 보고했기 때문이다.

## 5. 검증 결과

중단 시점 main(`78d2650`)과 이 브랜치에서 확인했다.

- `npm test`: 테스트 파일 29개, 테스트 534개 통과
- `npm run build`: 통과
- `npm run lint`: 이 수정 전에는 `.claude/worktrees/` 사본에서 오류 639건이 나왔다. `src`만 검사하면 오류가 없었고, 수정 후 `npm run lint`도 오류가 없다.

### 알려진 제약과 후속 후보

각 기록의 "남은 작업"에서 중요한 것만 모았다.

- 구절 점프로 고른 구간 밖을 재생해도 연습 기록은 재생을 시작할 때 고른 구간으로 남는다(`2026-10-22-practice-log.md`).
- 백업을 불러와도 열려 있는 구간·매핑·리포트 화면은 새로고침 전까지 바로 바뀌지 않는다(`2026-10-21-json-backup.md`, `2026-10-22-practice-report.md`).
- 구간 이름 바꾸기, 삭제, 시작·끝 수정 기능이 없다(`2026-10-21-section-marking.md`).
- 구절 시간 순서가 어긋나도 안내하지 않는다(`2026-10-21-lyric-mapping-editor.md`).
- `storage.ts`가 설정값의 범위(프리롤 0 이상, 유사도 0~1)를 읽을 때 확인하지 않는다(`2026-10-21-settings-panel.md`, `2026-10-22-similarity-threshold.md`).
- PRD "개발 후 점검 항목"(장시간 안정성, 영상 호환성, 이동 오차 ±1초, 스피커 환경)은 손대지 않았다.
